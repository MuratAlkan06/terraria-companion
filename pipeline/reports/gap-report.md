## TO-VERIFY-IN-P2 resolutions

- **#1 Cargo Items columns / class / rarity** — Cargo Items has 43 columns (itemid, name, internalname, image, imagefile, imageplaced, imageequipped, autoswing, stack, consumable, hardmode, type, listcat, tag, damage, damagetype, defense, velocity, knockback, research, rare, buy, sell, axe, pick, hammer, fishing, bait, bonus, toolspeed, usetime, unobtainable, critical, tooltip, placeable, placedwidth, placedheight, mana, hheal, mheal, bodyslot, buffs, debuffs). `type` is a ^-list of infobox types ("weapon", "tool", "ammunition", …); `damagetype` is the class as text (Melee/Ranged/Magic/Summon, empty for classless) and agrees with the Iteminfo class flags for every identified weapon (455 agree, 0 mismatch, 33 with no wiki class: 32 classless in both sources, 1 with an Iteminfo class only); `rare` is the game rarity number (plain or wrapped in the rarity template "Rarity level: N"; 488/488 weapons agree with Iteminfo); `critical` = 4 + Iteminfo crit (391 agree, 0 mismatch); `usetime` = Iteminfo useAnimation; `velocity` is the effective projectile velocity (equals Iteminfo shootSpeed for 330 weapons, differs for 95 — extra updates / ammo), so it is not cross-checked. `tag` carries vendor:<NPC> (purchase routes), `listcat` route hints; `stack` reports 9999 for weapons (B7 — maxStack only for consumable weapons, from Iteminfo).
- **#9 special rarity tiers** — Module:Iteminfo/data `rare`: -1 gray, 0–11 numeric tiers, -11 amber (quest fish + Strange Plants), -12 rainbow (Expert items; flag expert:true, base tier in `rarity`), -13 fiery red (Master items). Cargo `rare` uses the same numbers (Shield of Cthulhu -12, Eye of Cthulhu Relic -13). Mapped to Rarity -1..11 | "amber" | "rainbow" | "fiery-red"; 0 weapons use a special tier (weapon rarities span 0–10).
- **#10 useTime vs useAnimation** — The wiki's "Use time" equals Iteminfo useAnimation for 488/488 weapons with a wiki value (useTime differs from the wiki value for 42, e.g. Zenith useTime 10 / useAnimation 30). useAnimation = length of one use (attack cycle); useTime = interval between successive uses/shots within it (bursts, multi-swing projectiles). Emitted: useTimeTicks = useTime, useAnimationTicks = useAnimation (both always present). Display "Use time" from useAnimationTicks (wiki parity); attack cycles per second = 60 / useAnimationTicks; useAnimationTicks was added to the weapons list projection for that reason.
- **#11 ammo modifier location (weapon side)** — A weapon's ammo class is Iteminfo `useAmmo` = the game's AmmoID, i.e. the item ID of the class's representative item (40 Wooden Arrow, 97 Musket Ball, 771 Rocket I, 23 Gel …); ammo items carry the same value in `ammo` plus their own `damage`, `knockBack` and `shootSpeed`, which the game adds to the weapon's. ammoClass = slug of the representative item's name (17 classes among weapons: acorn, ale, candy-corn, copper-coin, explosive-jack-o-lantern, fallen-star, flare, gel, musket-ball, nail, rocket-i, sand-block, seed, snowball, stake, stynger-bolt, wooden-arrow). Velocity MULTIPLIERS (B2, e.g. Musket Ball) and per-weapon ammo conversions are not item fields in Iteminfo — they come from projectile code and remain wiki-text facts for the ammo slice (P2-S7). Rule 10 (ammo match) is deferred while items are pending.
- **D1 caveat: 1.4.5.7 → 1.4.5.8 patch diff** — The 1.4.5.8 patch notes (wiki page "1.4.5.8", rev 1029883) name three weapons — Clay Bud Staff (now always knocks enemies away), Last Prism (laser fades without enough mana), Acorn Slingshot (crash fix) — all behavioral; no numeric item stat changed, so no extracted field is in the patch-diff set. The Cargo cross-check above is the re-confirmation for every compared field.
- **critPct for summon weapons** — The wiki's Critical hit page (rev 1032172) states summon damage cannot normally deal critical hits, and the infobox shows no crit for all 64 summon weapons; critPct is therefore not applicable (absent, not listed). Classless weapons show no crit either but no rule is documented → Unknown.
- **#2 recipe-group encoding** — Cargo Recipes stores a group ingredient as its plain English name ("¦Any Iron Bar¦" in `ingredients`, "Any Iron Bar¦2" in `args`, "¦Any Iron Bar¦2" in `ings`); members are not in Cargo. Members come from Module:Recipes `group("Any …", {names})` (what the {{recipes}} template uses), resolved to IDs via Module:Iteminfo/data and cross-checked against Module:RecipeGroups (the game's SetupRecipeGroups, v1.4.5.4 transcription). Station alternatives (B3) come from Module:Recipes/l10n `en.station_cate` ("Iron Anvil" → "Iron or Lead Anvil").
- **#3 drop NPC ids / multi-part bosses** — Cargo Drops `id` carries NPC ids for most NPC rows (single, comma lists, ranges, per-variant notes, negative variant netIDs); container rows (crates, chests, treasure bags) carry none or the boss id. Ids are cross-checked against Cargo NPCs by name (mismatches withheld + gap); empty ids are filled from NPCs. Multi-part bosses: every part/segment NPC is typed `boss Part` and lives on the boss article (`_page`), so drops attribute to that boss. bossId stays absent + listed until the P2-S6 boss registry exists.
- **#8 Imageinfo → sprite file resolution** — Cargo Items `imagefile` names the infobox image ("Zenith.png"); `prop=imageinfo&iiprop=url|size|sha1|mime` on "File:<imagefile>" (50 titles per request) returns the original file URL on terraria.wiki.gg/images/, its SHA-1, size and dimensions; the URL's ?<6 hex> key is the SHA-1 prefix (pins the file version). The wiki's CDN (Cloudflare Polish, `cf-polished: ok, orig_size=N`) serves most PNGs re-encoded, so a byte-exact SHA-1 match is only possible for some files; downloads are accepted when the SHA-1 matches exactly OR the CDN-reported original size equals the wiki's recorded size of that version (pipeline:sprites reports both counts).
- **#13 Cargo paging** — limit=5000 requested; the server returned at most 500 rows per page for every table (Recipes 9 pages, Drops 7, NPCs 2, Items 13, Weapon_source 3). Pagination is by offset ordered by _ID until COUNT(*) is reached.
