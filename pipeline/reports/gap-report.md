- **no-known-route**: an input item has no recipe or drop in the datasets (base materials, vendor/fishing/chest-only items: item corpus P6-S0)
- **drop-source-ungated**: a drop comes from an enemy, an event boss or a container whose own gating is not verified (Enemy.stage Unknown; event bosses are progression markers, not Boss records; containers carry no gating data)
- **boss-attribution-pending**: a boss drop has no verified boss → progression-node attribution (source.bossId Unknown: the row's NPC ids disagree with the registry boss)
- **drop-conditions-unknown**: a drop lists its conditions as Unknown
- **vendor-conditions-unknown**: a purchase route exists but the shop availability conditions are not structured on the wiki
- **progression-graph-pending**: a gate maps to a progression node that is not in the dataset, so the stage cannot be computed
- **acquisition-withheld**: the item's acquisition is withheld because wiki sources conflict (AMENDMENTS-004 B19)
- **alternative-route-unverified**: one route is derivable, but another route is not, and it could be the less gated one — the minimum over routes is unknown (§7b)
- **cycle**: every route needs the item itself (recipe cycle)

## TO-VERIFY-IN-P2 resolutions

- **#4 NPCs table per-difficulty hp/defense** — Cargo NPCs `life` / `defense` / `damage` are rendered infobox cells: a per-difficulty block (`npcstat` or `mode-content` with m-normal / m-expert / m-master / m-expert-master / m-all spans), or a bare integer for every difficulty (6 of 1,538 cells). Additional lines are alternative values (enraged, per-health, with minions) or — after a "(contact)" note — projectile damages; cells can carry the wiki's "based on outdated versions of Terraria's source code" category flag. pipeline/parse/npcStats.ts keeps only one integer per difficulty and withholds everything else; a boss difficulty is emitted only with both hp and defense verified (6/18 bosses).
- **#1 Cargo Items columns / class / rarity** — Cargo Items has 43 columns (itemid, name, internalname, image, imagefile, imageplaced, imageequipped, autoswing, stack, consumable, hardmode, type, listcat, tag, damage, damagetype, defense, velocity, knockback, research, rare, buy, sell, axe, pick, hammer, fishing, bait, bonus, toolspeed, usetime, unobtainable, critical, tooltip, placeable, placedwidth, placedheight, mana, hheal, mheal, bodyslot, buffs, debuffs). `type` is a ^-list of infobox types ("weapon", "tool", "ammunition", …); `damagetype` is the class as text (Melee/Ranged/Magic/Summon, empty for classless) and agrees with the Iteminfo class flags for every identified weapon (455 agree, 0 mismatch, 33 with no wiki class: 32 classless in both sources, 1 with an Iteminfo class only); `rare` is the game rarity number (plain or wrapped in the rarity template "Rarity level: N"; 488/488 weapons agree with Iteminfo); `critical` = 4 + Iteminfo crit (391 agree, 0 mismatch); `usetime` = Iteminfo useAnimation; `velocity` is the effective projectile velocity (equals Iteminfo shootSpeed for 330 weapons, differs for 95 — extra updates / ammo), so it is not cross-checked. `tag` carries vendor:<NPC> (purchase routes), `listcat` route hints; `stack` reports 9999 for weapons (B7 — maxStack only for consumable weapons, from Iteminfo).
- **#9 special rarity tiers** — Module:Iteminfo/data `rare`: -1 gray, 0–11 numeric tiers, -11 amber (quest fish + Strange Plants), -12 rainbow (Expert items; flag expert:true, base tier in `rarity`), -13 fiery red (Master items). Cargo `rare` uses the same numbers (Shield of Cthulhu -12, Eye of Cthulhu Relic -13). Mapped to Rarity -1..11 | "amber" | "rainbow" | "fiery-red"; 0 weapons use a special tier (weapon rarities span 0–10).
- **#10 useTime vs useAnimation** — The wiki's "Use time" equals Iteminfo useAnimation for 488/488 weapons with a wiki value (useTime differs from the wiki value for 42, e.g. Zenith useTime 10 / useAnimation 30). useAnimation = length of one use (attack cycle); useTime = interval between successive uses/shots within it (bursts, multi-swing projectiles).
