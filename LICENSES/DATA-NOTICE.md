## Files covered

| Path | What it is |
|---|---|
| `src/data/*.json` | The site's datasets, generated by `npm run pipeline:build` |
| `pipeline/overlays/*.json` | Hand-curated corrections and decisions that restate or interpret wiki facts (most entries name the wiki page they draw on) |
| `pipeline/fixtures/sample/*.json` | Test fixtures sampled from the datasets |
| `pipeline/reports/gap-report.md` | The dataset gap report (what is missing or Unknown, and why) |
| `public/sprites/manifest*.json` | Sprite provenance records — **metadata only**; the images they describe are not covered (see below) |

## Changes made

The wiki material was modified: values were extracted, normalized, cross-checked and combined across pages
into one dataset pinned to a single game version (`gameVersion` in `src/data/meta.json`, desktop). Values the
pipeline could not verify are recorded as Unknown, never guessed (`_prov.unverifiedFields`); values the wiki
states inconsistently are withheld; values worked out by a documented rule are marked as derived
(`_prov.modeledFields`); curated editorial values are marked (`_prov.editorialFields`). The pipeline and its
rules are documented in `docs/DATA_SCHEMA_SPEC.md`.
